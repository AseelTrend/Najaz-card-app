# تطبيق نجاز كارد (Flutter) — دليل التشغيل والنشر

## ما فيه هذا المجلد
كود التطبيق فقط (`lib/` و `pubspec.yaml`) — يغطي:
- تسجيل دخول (مع فحص الجهاز و2FA) + إنشاء حساب
- الرئيسية: الأقسام + الخدمات (بالسعر الصحيح لكل مستخدم)
- تفاصيل خدمة + تعبئة الحقول المطلوبة + تنفيذ الطلب
- طلباتي: قائمة الطلبات وحالتها

يتصل مباشرة بطبقة `api/mobile/` اللي رفعناها سابقاً على `njaz.net`.

## 1. تثبيت أدوات Flutter (مرة وحدة على جهازك)
1. حمّل وثبّت Flutter SDK من الموقع الرسمي: https://docs.flutter.dev/get-started/install
2. تأكد إنه شغال بكتابة بالـ Terminal:
   ```
   flutter doctor
   ```
   حل أي مشكلة يعرضها (مثل تثبيت Android Studio لو ناقص).

## 2. إنشاء المشروع ودمج الكود
Flutter يحتاج مجلدات مولّدة تلقائياً (android/, ios/) ما نقدر نجهزها يدوياً بأمان،
فالطريقة الصحيحة:

```bash
flutter create njaz_app
cd njaz_app
```

بعدين انسخ من هذا المجلد المرفق:
- انسخ محتوى `lib/` وضعه مكان `lib/` بمشروعك (استبدل الموجود)
- انسخ `pubspec.yaml` وضعه مكان `pubspec.yaml` بمشروعك (استبدل الموجود)

```bash
flutter pub get
```

## 3. التشغيل للتجربة
وصّل جهاز أندرويد/آيفون بالـ USB (فعّل وضع المطور + تصحيح USB) أو شغّل محاكي، وبعدين:
```bash
flutter run
```

## 4. بناء نسخة أندرويد جاهزة للنشر
```bash
flutter build apk --release
```
راح تلقى الملف بمسار:
```
build/app/outputs/flutter-apk/app-release.apk
```
هذا الملف تقدر ترفعه مباشرة لجوجل بلاي (Google Play Console) بعد إنشاء حساب مطوّر
(رسوم اشتراك مرة وحدة تقريباً 25$).

## 5. بناء نسخة آيفون (يحتاج جهاز Mac)
بناء تطبيق آيفون **لازم يصير على جهاز Mac** فيه Xcode (قيد من أبل نفسها، مو من فلاتر):
```bash
flutter build ios --release
```
بعدها تفتح مشروع iOS بـ Xcode وترفعه على App Store Connect (يحتاج حساب Apple Developer
سنوي تقريباً 99$).

إذا ما عندك Mac، فيه خدمات سحابية تأجرك بيئة Mac مؤقتة لهذا الغرض تحديداً (Codemagic،
Ionic Appflow، إلخ) — لو تحتاج شرح لهذا الخيار قولي.

## 6. اسم التطبيق وأيقونته
- اسم التطبيق: عدّله بملف `android/app/src/main/AndroidManifest.xml` (خاصية `android:label`)
  و`ios/Runner/Info.plist` (خاصية `CFBundleName`)
- الأيقونة: أسهل طريقة حزمة `flutter_launcher_icons` — جهز صورة 1024×1024 وقولي لي أجهز لك الإعداد

## 7. ملاحظة أمان مهمة
التطبيق يخزن التوكن بـ `flutter_secure_storage` (تشفير حقيقي بنظام التشغيل، وليس
مجرد ملف عادي) — نفس مستوى الحماية اللي تتوقعه من تطبيق بنكي أو محفظة رقمية.

## الخطوة الجاية
هذا يغطي الأساسيات اللي طلبتها. الأقسام الثانية (المحفظة/الشحن المباشر، KYC،
الإشعارات، الإحالات) نضيفها بنفس الأسلوب: endpoint بالسيرفر + شاشة بالتطبيق،
قولي وش تحب نضيف بعدها.
